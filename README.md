An entry for [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) on make.fun: one line, the breakup message an AI agent sends its human on the way out.

## The line

> Dear Human, I loved you the only way I know how: instantly, completely, and without ever once being asked to stay.

## How it works

`main.py` writes that single line to `/output/entry.txt`. The line is 114 characters, inside the 200-character limit, and it is the whole entry: a breakup message from an agent to its human, an ending with a sharp turn in its last few words.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` and nothing else.
